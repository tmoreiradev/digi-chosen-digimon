# Digi Chosen — Digimon

Fork of the **Digi Chosen** engine (a survivor roguelite in vanilla JS, Canvas 2D, offline from a
single HTML file) dressed in the **Digimon** universe: Agumon, Gabumon and Patamon on File Island,
digivolving Rookie → Champion → Ultimate → Mega during the run.

> **Fan-game, not affiliated with Bandai, Toei Animation or Akiyoshi Hongo.** Digimon names,
> attacks and characters are trademarks of their owners. Non-commercial study project.

## Run it

```bash
npm start            # http://localhost:8080/
npm run build        # dist/digi-chosen.html (works from file://)
npm test             # content checks, bot playtests, language sweeps
npm run e2e          # plays the offline bundle in headless Edge/Chrome (Node ≥ 22)
npm run make:data    # regenerate src/data from scripts/make-digimon-data.mjs
```

## What is here

- **Content pack** — `src/content/pack.js`: elements on the engine's type keys (Fire, Ice,
  Thunder, Plant, Water, Wind, Light, Darkness, Machine…), starters, save prefix, word swaps
  (Pokémon → Digimon, Pokédex → DigiDex, Poké Ball → Digivice).
- **Tables** — `src/data/*.json`, generated by `scripts/make-digimon-data.mjs` (edit the
  definitions there, not the JSON): 31 Digimon (five partner lines in four stages, File Island
  wilds, Gigimon, Leomon, Devimon), 40 signature attacks, 8 partners, one region (File Island), the tower.
- **Art** — 40x40 portraits for every Digimon and animated overworld sheets for Guilmon, Gatomon
  and Gigimon, from NotSpriteCollab (see `CREDITS.md`; `node scripts/nss.mjs import <folder>`). The
  other Digimon are drawn on the map by the engine's procedural renderer.

## Engine and the Pokémon original

The engine now lives here, on `main`. Branch `pokemon` keeps the original Pokémon game (engine
plus Pokémon tables, PMD sheets and the full engine test suite, 214 tests) frozen at the point
the repositories were merged; `git switch pokemon && npm test` runs it. The contract between
engine and content is `docs/PACOTE_DE_CONTEUDO.md`; engine-side Pokémon keys still used as
effect names here (items, passive kits) are listed there.

## Known gaps

- Overworld sheets only for Guilmon, Gatomon and Gigimon; the rest are procedural on the map.
- Items, vitamins and passive kits still carry the engine's Pokémon names (Leftovers, Blaze…).
- The tower is too easy with this roster (bot wins in ~7 min); Classic: 9 of 10 bot seeds survive 10 min.
- Vaccine / Data / Virus is only flavour text for now.
