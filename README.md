# Digi Chosen — Digimon

Fork of the **Digi Chosen** engine (a survivor roguelite in vanilla JS, Canvas 2D, offline from a
single HTML file) dressed in the **Digimon** universe: Agumon, Gabumon and Patamon on File Island,
digivolving Rookie → Champion → Ultimate → Mega during the run.

> **Fan-game, not affiliated with Bandai, Toei Animation or Akiyoshi Hongo.** Digimon names,
> attacks and characters are trademarks of their owners. Non-commercial study project.

## Run it

```bash
npm start            # http://localhost:8080/
npm run build        # dist/digi-chosen.html (works from file://)
npm test             # content checks, bot playtests, language sweeps
npm run e2e          # plays the offline bundle in headless Edge/Chrome (Node ≥ 22)
npm run make:data    # regenerate src/data from scripts/make-digimon-data.mjs
```

## What is here

- **Content pack** — `src/content/pack.js`: elements on the engine's type keys (Fire, Ice,
  Thunder, Plant, Water, Wind, Light, Darkness, Machine…), starters, save prefix, word swaps
  (Pokémon → Digimon, Pokédex → DigiDex, Poké Ball → Digivice).
- **Tables** — `src/data/*.json`, generated by `scripts/make-digimon-data.mjs` from the roster in
  `scripts/digimon-species.mjs` (edit there, not the JSON): 140 Digimon from Adventure, Adventure 02
  and Tamers — 17 partner lines (Agumon, Gabumon, Patamon, Tentomon, Palmon, Gomamon, Biyomon,
  Salamon, Veemon, Hawkmon, Armadillomon, Wormmon, Guilmon, Terriermon, Renamon, Monodramon,
  Impmon), wild Rookies and Champions, Ultimates and the Mega villains (Dark Masters, Daemon,
  MaloMyotismon, Apocalymon…) as bosses; 77 signature attacks; one region (File Island).
- **Art** — 40x40 portraits for 131 of the 140 Digimon and full animated overworld sheets for Guilmon,
  Gatomon and Gigimon, from NotSpriteCollab (see `CREDITS.md`; `node scripts/nss.mjs import <folder>`).
  The other 137 have an 8-direction walk sheet generated with the Codex CLI in the same PMD style
  (`node scripts/codex-sprites.mjs`, resumable; `scripts/recell.mjs` re-cuts drawings that drift off
  the grid); the renderer animates their attack, hurt and faint from the walk frames.

## Engine and the Pokémon original

The engine now lives here, on `main`. Branch `pokemon` keeps the original Pokémon game (engine
plus Pokémon tables, PMD sheets and the full engine test suite, 214 tests) frozen at the point
the repositories were merged; `git switch pokemon && npm test` runs it. The contract between
engine and content is `docs/PACOTE_DE_CONTEUDO.md`; engine-side Pokémon keys still used as
effect names here (items, passive kits) are listed there.

## Known gaps

- Generated sheets have a walk cycle only (idle reuses it); the art is AI-made and uneven in places — a few
  (Tentomon, Togemon, Frigimon…) keep the same pose in every direction.
- No NSS portrait for ExVeemon, Paildramon, Ogremon, Datamon, Phantomon, BlackWarGreymon, Daemon, MaloMyotismon, MarineAngemon.
- Still one region for all 140 Digimon.
- Passive kits keep the engine's keys (blaze, torrent…); their names never reach the screen.
- Balance is bot-tuned only: the tower bot wins 3 of 5 seeds in 8.5–10 min (level 25–38); Classic: 10 of 10 seeds
  survive 10 min (level 24–35).
- Vaccine / Data / Virus is only flavour text for now.
